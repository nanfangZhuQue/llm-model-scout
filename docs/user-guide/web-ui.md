# 同源 Web UI 使用教程

适用版本：0.6.1 · 更新日期：2026-10-02

0.6.1可直接输入服务商名称、协议地址、Key与代理，并自动加密保存；推荐先看[无配置快速使用](quick-start.md)。页面会在输入及明确配置导出时处理Key，不把Key保存在浏览器storage；普通任务报告继续脱敏。

在新增或编辑服务商时可启用「OpenAI Responses 兼容接口」，填写该入口的 Base URL 和 Key，然后保存。创建任务时可单选 `responses`，也可按「全部入口」批量验收。目录和结果支持协议筛选，同名模型按入口独立选择和统计。对于没有列表接口的服务商，可直接使用「验证指定模型」。

## 1. 启动

在项目根目录执行：

```powershell
.venv/Scripts/python -m pip install -e ".[agent]"
.venv/Scripts/python -m llm_model_scout agent --config providers.local.toml
```

打开 `http://127.0.0.1:8766/`。自定义--port时使用对应端口，不能换成未允许的域名或公网地址。

先不连接真实服务商体验：

```powershell
.venv/Scripts/python examples/web_demo.py
```

此示例启动本地mock与UI，默认使用8766端口。`mock-ok`返回合成文本，`mock-missing`模拟不存在；手动输入`mock-slow`可观察慢请求与取消。不要把mock结果当成实际模型可用性证据。

## 2. 登录

从Agent启动时指定的Token文件复制会话Token，默认`.scout/agent.token`，粘贴到“Agent 会话 Token”。这是本地会话凭据，不是服务商API Key。

- Token只在页面内存，成功连接后输入框清空。
- 不写入URL、localStorage、sessionStorage或cookie。
- 刷新、离开页面或退出后重新连接；重新登录可获取Agent仍保留的任务。
- 退出页面后，后台任务继续执行。使用同一数据目录重启 Agent 后，可查询保留的历史。
- 401会清空连接状态并停止轮询；不会自动尝试其他凭据。

## 3. 创建扫描

工作台提供「批量验收」和「验证指定模型」。选择后，预览区会显示所选协议、目标数或待发现状态、各入口 Token 上限、任务预算和共享剩余额度。实际请求上限基于当前快照，提交后仍由 Agent 逐次检查额度。

使用「验证指定模型」时选择一个入口，输入完整模型 ID。共享额度足够时，Agent 向该模型发起一次验证，跳过列表发现，重试为零。即使服务商的模型列表接口不可用，也可以通过模型 ID 验证。结果表展示 HTTP 状态、诊断及实际尝试次数。

### 批量验收

1. 选择服务商：来自本机加密存储；点击新增/编辑可管理地址、Key和代理。使用旧--config只读模式时管理按钮隐藏。
2. 选择一个协议入口；多入口可显式选择“全部入口”，分别验证、共享额度。
3. 模型来源选择“沿用配置 / 自动发现”，会保留服务端配置中的手动候选；选择手动列表时每行一个ID，去空行/去重并保留大小写。
4. profile、Token上限、请求预算与任务截止时间留空时沿用服务端配置，显式填写才覆盖。页面展示可用上限与剩余额度。
5. 点击“创建扫描任务”才会发起扫描。按钮防止当前请求未完成时重复提交。

从已发现的目录发起「测试所选」或「测试全部（重新发现）」时，先查看各自的预算预览。手选候选的数量由所选入口和模型决定。重新发现时会显示「待发现」，预算上界计入发现分页和重试。

在「探测能力」选择「流式文本」可用同一表单执行快速验证、批量和目录验收。预算预览和结果会显示所选能力。流式目标只有收到完整终止事件后才可能通过，首段文本之后仍可取消。历史对比中不同能力的结果会标记为未配对。

选择「结构化输出」会发送固定 JSON Schema。结构化结果分别显示 JSON 无法解析及 Schema 不匹配。提交前可核对所选入口、Token 上限与请求预算，历史和导出也会标明能力。

选择「工具调用」可验证模型返回的合成工具指令。结果区分别显示未返回工具调用、工具名不匹配、参数无效或多次调用。确认指令后探测即结束。[能力与结果判据](../design/architecture.md#t11-工具调用探测)

真实扫描可能收费。请求预算包含发现和重试，不能把它等同于Token预算；累计额度耗尽时创建按钮禁用。创建请求网络超时后先刷新任务列表确认，避免重复创建。

## 4. 任务和进度

- 任务列表按创建时间倒序显示，每页 50 条，可分页和按服务商筛选。筛选使用历史中保留的服务商选项，和创建扫描时选择的服务商独立。
- 发现阶段显示各入口汇总后的候选数。计划形成后，详情显示「已验证 / 计划目标数」及进度条。仅发现任务显示候选数，空计划显示无验证目标。
- 取消、超时或请求预算耗尽时，进度保留实际已验证比例，并在详情中显示计划内的跳过和取消数量。
- 运行和排队任务可取消；“正在取消”不等于已经取消，最终状态由服务端确认。
- 正常状态约每1.5秒轮询一次；网络异常约5秒后重试，也可点击“立即刷新”。轮询不重叠，切换/退出会取消旧读取并忽略过期响应。
- 超出保留上限的任务返回 404。中断任务显示已提交的进度，只有保存过发现或模型结果时才提供部分报告下载。

### 两次扫描对比

打开一条已结束且有报告的任务，在详情点击「设为基准」。打开另一条任务并点「设为本次」。两条记录可以来自不同历史页面。有多个共同入口时，在「对比协议入口」中选择。

对比区同时显示两次的验证结论、探测条件和目录覆盖。可按模型 ID 搜索，或筛选验证变化、未测和目录变化。条件已变化或无法确认时，查看两侧原始结论及差异提示。只选测部分模型时，未取得结论的目标显示对应一侧未测。只有两次都完整获取了可比的 API 目录时，才会显示本次目录新增或未列出的模型。

### 按差异复测

在对比表勾选差异或未测的模型，点击「复测所选」。同一入口内切换搜索和筛选时会保留勾选。新任务只验证勾选的目标，沿用「本次」来源任务保存的探测配置，并使用服务商当前连接与共享请求配额。

如果连接信息发生变化，页面会显示差异。核对后点击「确认使用当前连接复测」。入口已删除或协议已更改时，可继续查看原对比。复测任务详情的「来源对比」可以打开两条保留的来源任务。

## 5. 查看结果和下载

报告形成后显示模型/入口、可用状态、HTTP状态、错误/诊断、最后尝试耗时和次数。可按模型ID搜索，并按协议、状态、错误类别组合筛选。

- 运行中先看进度条与数值进度，报告未形成前不展示伪造结果。
- “执行完成”只代表任务完成，不代表所有模型通过。
- 下载JSON/XLSX携带鉴权头，Token不拼接到下载链接。XLSX分“全部”和“仅通过”两种：仅通过只导出available行，无通过模型时为仅表头；文件名为“服务商名称-年月日-时分秒（-仅通过）.xlsx”，时间取任务完成/创建时间。
- 导出包含整个任务报告，不受页面筛选影响。
- 部分报告会显示「部分报告」标记，下载名含 `-partial`（JSON）或「部分」（XLSX）。
- 窄屏结果表可在表格区域横向滚动，页面本身不横向溢出。
- 主题按钮切换明暗；刷新后回到系统主题，不持久化偏好。

字段、诊断及CSV防护详见[报告说明](reports-and-troubleshooting.md)。

## 6. 新增接口与安全

鉴权的 `GET /scans` 提供跨会话分页和服务商筛选，查询、查看详情和下载都使用本地已保存的数据。[Agent 教程](agent.md)

`GET /providers`增加入口probe、是否有配置候选、模型/Token/超时限制等安全概要；不返回供应商Key、代理密码或配置路径。

仅`/`、`/ui/app.js`、`/ui/app.css`、`/favicon.svg`静态GET/HEAD及原health可以匿名读取；仍校验Host/Origin。数据API继续Bearer鉴权，未开放通配CORS。CSP只允许同源脚本/样式/连接，禁止iframe嵌入；页面无外部CDN。结果文本通过DOM textContent渲染，不把模型名或错误当成HTML执行。

## 7. 浏览器验收与限制

已通过会话连接的Playwright浏览器验证登录/错误Token、创建、筛选、JSON/CSV下载、取消、过期响应防护、断线恢复、401/404、刷新重连、恶意模型名纯文本、零浏览器存储及桌面/390px暗色布局。

截图在开发工作区`.scout/ui-desktop.png`与`.scout/ui-mobile-dark.png`，不进入分发包。网络失败/401等场景会产生预期的HTTP控制台记录，不等于未捕获JavaScript异常；已执行场景未出现未捕获页面异常。

可复现的原生Python Playwright脚本：

```powershell
.venv/Scripts/python -m pip install -e ".[browser]"
.venv/Scripts/python -m playwright install chromium
.venv/Scripts/python scripts/test_web_ui.py
```

早期原生 Playwright 和全新 wheel 验收见[验收记录](../development/acceptance.md)。跨会话分页和完整、部分报告下载的实测记录见[开发进度](../development/progress.md)。
