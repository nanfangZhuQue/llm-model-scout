# 文档维护规则

生效日期：2026-10-01 · 对应REQ-013

## 原则

业务需求新增、删除、修改时，在同一开发任务中更新对应文档。没有实现的需求写成“待开发”，未经验证的能力写成“待验证”；不能只改README，也不能只在聊天里留下结论。

当前文档只有一份权威正文：需求在requirements，架构在design，操作在user-guide，进度/变更在development。根README与CLAUDE.md保持摘要和链接；历史资料移入archive，不复制回现行正文。

## 变更影响矩阵

| 变更类型 | 必须核对/更新 |
|---|---|
| 新增/删除业务能力 | PRD需求ID、progress任务状态、changelog；涉及用户操作时更新教程 |
| 协议或认证变化 | PRD、architecture、configuration、相关测试和示例 |
| CLI/环境变量/默认值变化 | configuration、getting-started受影响步骤、PRD默认表、测试 |
| JSON/错误类别/退出码变化 | reports-and-troubleshooting、PRD结果规则、schema与契约测试 |
| 架构/依赖/开发命令变化 | architecture、development-guide、CLAUDE.md、构建/CI |
| 验证结果或交付状态变化 | progress；真实服务商实测另更新provider-tests |
| 文档路径迁移 | docs/README导航、README、CLAUDE.md、内部链接、检查脚本和分发白名单 |

## 每次变更的完成清单

1. 分配或引用REQ编号，说明新增/调整/修复的内容及原因。
2. 在changelog记录日期、范围、兼容性影响与涉及文档；未批准的提议不得直接写成当前能力。
3. 修改代码与测试，同步影响矩阵对应文档和示例。
4. 更新progress，记录已执行命令、结果与尚未验证项。
5. 执行`python scripts/check_docs.py`，以及受影响的测试；写明失败或跳过项。
6. 若某类文档不受影响，在变更条目中说明，不做无意义的时间戳改动。
7. 最终回复列出行为变化、文档位置、验证结果和限制，并推荐下一步开发计划，直到已确认需求完成；候选功能不能自动当作已确认需求。

## OpenRouter持续自测授权（2026-10-01）

用户明确授权本项目自测可调用指定OpenRouter（https://openrouter.ai/api/v1），不需逐次确认Token消耗。调用以验证当前功能为目的，仍设置合理超时/重试，避免与验证无关的流量；此授权不扩展到其他服务商。密钥只放在受控运行环境，不写入项目文件或测试源码；不能把费用授权当成保存/泄露凭据的授权。密钥失效或缺失时请求用户安全配置，而不是改用未授权账号。

这条规则取代此前各任务“仅mock/不使用历史凭据”的未来执行限制，但历史测试记录不变。真实调用结果按事实记录，不为获得成功而改写判定标准；mock与真实观察始终分开。

## 自动提醒与检查

本项目的本地Claude Code配置增加两个命令hook：

- UserPromptSubmit：提示按此矩阵同步文档；不解析、保存或输出用户prompt，因此不会把用户粘贴的Key写入文件。
- Stop：运行文档链接/必需文件检查；失败时要求修复，已进入stop-hook续轮时只提示以避免循环。

hook调用`scripts/check_docs.py --hook`。提醒不等于自动理解需求，更不等于文档已被更新；内容同步仍由开发者/编码助手执行。其他编辑器或手动改文件不会触发Claude hook，应手动运行检查并遵守清单。没有后台任务持续监控文件，也不会自动调用服务商或改写需求。

hook只写入本项目现有settings.local.json，保留原有模型、env等配置。它是机器本地设置、不进入分发包；其他开发者需要自行配置。可通过Claude Code的/hooks检查或关闭，必要时重新启动会话载入。脚本仅使用Python标准库。

## 本机保存与敏感导出（0.6.0）

用户已选择自动本机保存；允许经系统保护加密后保存服务商Key，不允许源码、普通配置、日志或报告中意外出现明文Key。用户明确确认的完整连接配置导出可以包含Key/代理密码，应标注敏感文件并排除Git。此规则取代旧版本“所有导出都不得含Key”的绝对表述，普通测试报告仍脱敏。

默认数据位于用户应用数据目录，不能假设.gitignore能保护任意手工上传文件；上传云仓库前检查个人配置、数据库、Token和exports。删除本机记录不宣称磁盘安全擦除。

## 历史和版本

应用版本、报告schema_version、文档版本分别管理。纯文档重组不冒充新功能版本。archive保留原文和当时状态，不再日常改写；目录说明明确它不是现行需求。根task_plan/findings/progress仅供规划工具兼容，新增正文写到docs/development。
